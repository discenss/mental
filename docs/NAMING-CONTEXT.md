# Выбор названия продукта — контекст разговора (2026-08-23)

> Хендофф для параллельной сессии. Текущее рабочее название — **Mental Club**, ищем замену.
> Проект: `~/dev/mental`. Продуктовая документация: [RUNBOOK.md](RUNBOOK.md),
> [mental-architecture.md](mental-architecture.md).

---

## 1. Требования к названию (выведены в ходе разговора)

1. **Английское.** Продукт выводится на англоязычный рынок, планируется App Store.
   Контент при этом русский (озвучка, YAML) — имя латиницей, тексты русские.
2. **Неговорящее / тема-нейтральное.** В продукте **10 направлений** (тревога, эмоции,
   прошлый опыт, выгорание, фокус/прокрастинация, самооценка, отношения, границы,
   паттерны, поиск себя) + партнёр планирует **вертикаль для спортсменов**.
   Любое «говорящее» имя описывает одну тему и врёт про остальные девять.
   Объяснение продукта — работа тэглайна и первого скриншота, не имени
   (как Calm / Headspace / Balance / Finch — ни одно не говорит, что внутри).
3. **Произносимо однозначно.** Одно чтение, набирается на слух в поиске App Store.
4. **Свободно в App Store** (категория Health & Fitness) — не только домен.
5. **Растяжимо** на 10 тем + спорт.
6. **Не медицинское.** Продукт с первого экрана говорит «мы не ставим диагнозов»
   (`bot/texts.py`, ONBOARD_INTRO) — название не должно противоречить.
7. Тон существующего копирайтинга: «спокойные 6-недельные маршруты», «шаг за шагом,
   в вашем темпе», «мягко и постепенно», 🌿.

## 2. Методика проверки (воспроизводимая)

**App Store** (без ключа, публичный iTunes Search API):
```bash
curl -s "https://itunes.apple.com/search?term=<НАЗВАНИЕ>&country=us&entity=software&limit=50"
# смотреть: точное совпадение trackName, кол-во приложений с префиксом,
# сколько из них в primaryGenreName == "Health & Fitness"
```

**Домены — только RDAP, whois-порт в песочнице закрыт:**
```bash
# правильные эндпоинты берутся из IANA bootstrap:
curl -s https://data.iana.org/rdap/dns.json
#   .com/.net -> https://rdap.verisign.com/com/v1/domain/<d>
#   .app/.day/.dev -> https://pubapi.registry.google/rdap/domain/<d>
# http 404 = СВОБОДЕН, http 200 = занят, 429 = rate limit (backoff ~20s)
```

⚠️ **ВАЖНО — ловушка, на которой уже ошиблись:** эндпоинт
`https://www.registry.google/rdap/domain/<d>` для `.app` **нерабочий** — отдаёт 404 на
любой домен, включая `google.app`. Первый прогон `.app`-доменов из-за этого был неверным.
**Всегда проверять контролем** (`google.app`, `google.day`, `calm.app` должны выйти «занят»).

**Товарные знаки — НЕ ПРОВЕРЕНЫ ни для одного варианта.** USPTO закрыл публичный API
(нужен ключ). Проверять вручную: https://tmsearch.uspto.gov — классы 9 (софт) и 44
(услуги здоровья). Обязательно до покупки домена.

**Google Play — не проверялся** ни для одного варианта.

## 3. Отклонённые варианты и причины

| Вариант | Причина отклонения |
|---|---|
| **Mental Club** (текущее) | «Mental» по-русски → «псих-», по-английски *mental* = «психованный» (брит. сленг); «Club» обещает сообщество, которого нет (продукт строго одиночный); английское имя при русском контенте |
| **Обратно к себе / Опора / Шаг за шагом** и др. русские | Отпали, когда выяснилось, что рынок англоязычный |
| **Mental Steady** | Возвращает проблему «Mental»; убивает спортивную вертикаль; прилагательное+прилагательное не читается как имя; сужает при 10 темах |
| **Steady Days** | **Точное совпадение в App Store:** `Steady Days` (Sean McNamara, Health & Fitness, `com.seanmcn.steady.days`, вышло 2026-05-01). Ниша «Steady» переполнена — **10 приложений** в H&F, из них 4 про трезвость/зависимости → ложная ассоциация. `steadydays.com` занят (рег. 2008) |
| **Groundwork** | 5 приложений в H&F (Groundwork MH, Groundwork Athletics, GroundWork Semi Private); `.com` и `.app` заняты |
| **Daylight** | Точное совпадение (Weather) + **Daylight — Worry Less** (Big Health, Medical) — прямой конкурент по теме тревоги; `.com`/`.app` заняты |
| **Throughline** | Точное совпадение (Games) + ThroughLine App (H&F); `.com`/`.app` заняты |
| **Waypoint** | **Точное совпадение прямо в Health & Fitness** + 21 приложение; `.com`/`.app` заняты |
| **Cadence** | 11 приложений в H&F — самая забитая ниша; `.com`/`.app` заняты |
| **Hesychia** (ἡσυχία, «внутреннее безмолвие») | Поле чистое, `.app` свободен — но **3 конкурирующих чтения** (англ. /ˌhɛsɪˈkaɪə/ vs /hɛˈsɪkiə/, греч. «хе-сю-ХИ-а», рус. «исихия»); `ch`=/k/ неочевидно; не диктуется голосом |

| **Kairos** (καιρός) | Точное совпадение (Productivity) + Kairos—Focus Habit, Kairos: Daily Devotional → ложная религиозная ассоциация; `.com`/`.app` заняты |
| **Meson** (μέσον, «середина», аристотелевская μεσότης) | Слово занято физикой (мезон — элементарная частица) + сеть Meson Sandwiches; `.app` занят |
| **Philautos** (φίλαυτος) | Домены свободны (`.com`!), поле чистое — но **значение отрицательное**: у Аристотеля = «себялюбивый, эгоистичный». Нейтральное — φιλαυτία (philautia) |
| **Paideia** (παιδεία, «формирование человека») | Смысл лучший из всех, App Store почти чист (0 в H&F) — но `.com` (рег. 1998, припаркован, eNom), `.app`, `.net` заняты; корень παῖς = «ребёнок» → педагогический оттенок. Свободны только `paideia.day`, `getpaideia.com` |
| **Tonos** (τόνος) | Ассоциация владельца: тонометр |
| **Metron** (μέτρον) | Ассоциация владельца: метроном |

| **Bathmo** | Обрубок βαθμός без «-ς» — перестаёт быть словом; «bath» слышится так же; открытый слог ослабляет |

Дают имена, которые на бумаге выглядят лучше, чем звучат вслух.

## 4. Bathmos — был финалистом, владелец засомневался

**βαθμός** — греч. «ступень, шаг, степень». Точно описывает механику (программа идёт
ступенями, «лестница 6 недель» в архитектуре).

Проверено (контроль пройден):
- App Store: **слова нет вообще** — в выдаче только «bath»-мусор (Bath & Body Works, детские игры)
- `bathmos.day` — **СВОБОДЕН**
- `bathmos.app` — **СВОБОДЕН**
- `bathmos.net` — **СВОБОДЕН**
- `getbathmos.com` — **СВОБОДЕН**
- `bathmos.com` — занят

**Сомнение владельца:** «звучит непонятно», смущает «-os» (хотя реальная проблема —
«bath»-омофон в начале). Решения нет, вариант подвешен.

## 5. Непроверенные идеи (на продолжение)

Греческие с внятной фонетикой: **Ethos** (ἦθος, «характер, нрав» — то, что формируется
практикой), **Anabasis** (ἀνάβασις, «восхождение»).

Короткие английские (подход «не искать красивое слово, а взять простое произносимое»,
как Calm/Finch/Balance): Even, Anchor, Ground, Tempo, Ridge, Verge, Ember, Lumen, Nord,
Tide, Onward, Pace, Stride, Ascend, Rise, Climb, Path, Poise, Ease, Level.

## 6. Что делать после выбора имени

**Переименование дешёвое:**
- `bot/texts.py` — `WELCOME`, `WELCOME_NEW`, `ONBOARD_INTRO` содержат «Mental Club» напрямую
- `docs/` — ONBOARDING.md, RUNBOOK.md, DEPLOY.md, mental-architecture.md
- **Внутренние код-имена НЕ трогать:** контейнеры `mental-backend`/`mental-db`/`mental-bot`,
  каталог `~/dev/mental`, коды `AUDIO_REAL_*`, `DATABASE_URL`. Не видны пользователю,
  переименование на живом сервере — риск без выгоды.

**Открытый вопрос:** имя латиницей в русских текстах («Это Bathmos 🌿») vs транслит
(«Батмос»). Рекомендация — латиница: одно написание для всех рынков, совпадёт с App Store.

## 7. Почему это блокирует инфраструктуру (и как расцепить)

Название понадобилось из-за **домена для WhatsApp**: Meta Cloud API забирает медиа только
по публичному HTTPS URL (или через upload в Graph API) — локального пути с volume, как
сейчас в Telegram (`bot/handlers/flow.py:312`), в WhatsApp не существует. Поэтому нужен
домен → отсюда «а как назовём».

**Рекомендация: расцепить.** Домен для раздачи аудио не обязан быть брендовым —
взять технический (`cdn.rhythmos.online` на уже работающем домене с валидным
сертификатом, стоит ноль) и разблокировать разработку. Имя выбирается спокойно,
к моменту публикации в App Store.

Подробности по WhatsApp-задаче — в разговоре: нужен Meta Business + номер (НЕ номер
Rhythmos — это другой проект), пароль sudo на сервере, и учесть что WhatsApp это
второй фронтенд (лимит 3 кнопок против 90 вопросов с 5 вариантами, нет
`edit_reply_markup`, шаблоны Meta для напоминаний вне 24-часового окна).
