# Тревога и внутреннее напряжение (ANX)

Направление уже участвует во входной самооценке
([../../../content/intake.yaml](../../../content/intake.yaml), 3 вопроса).
Контент программы получен от автора (17 файлов, 6 недель) и разложен сюда
по неделям. Идёт перенос в `content/modules/anx.yaml` (первая версия контента
без квизов и без части недельных самопроверок — см. ниже).

Фокус направления: наблюдение за тревогой, тело, тревожные мысли, контроль
и неопределённость, избегание, личный анти-тревожный протокол.

## Что лежит в этой папке

Авторские материалы — по одному комплекту на неделю (структура дня,
три текстовые практики, одна финальная аудиопрактика):

- `week-N-structure.md` — тема недели, цель, 7 дней (фокус/задание/рефлексия),
  где есть — недельная диагностика и персонализация.
- `week-N-text-practices.md` — 3 текстовые практики недели (дни 1–2/3–4/5–6).
- `ANX-WN-FINAL.md` — сценарий итоговой аудиопрактики дня 7 (текст для записи,
  ещё не озвучен — реальных mp3-записей пока нет).
- `OVERVIEW-source.md` — короткое маркетинговое описание (для кого / что
  делаем / что меняется) — черновая основа для паспорта модуля.

## Чем ANX отличается от BOUND/REAL — осознанно, по решению автора

- **Без квизов**: день состоит из фокуса, задания и 3 вопросов рефлексии
  (без отдельного кнопочного квиза).
- **Один финал на неделю, не 4 аудио**: вместо 4 аудио-слотов (A1/A2/A3/FINAL)
  у ANX на дни 1–6 — текстовые практики (`text_map`), а записывается только
  один аудио-сценарий в неделю (день 7). `check_module` под это ослаблен —
  число аудио/текстовых записей больше не фиксировано, проверяется только
  уникальность кодов.
- **Недельная диагностика (10 вопросов) есть не везде**: явно расписана для
  недель 1 и 5 в исходниках; для 2–4, 6 — добавится позже, когда пришлёт автор.
  Там, где её нет, неделя просто не имеет `selfcheck`/`zones` — бэкенд и бот
  это уже умеют (после недели сразу открывается следующая, без вопросов).
- **`postmodule_kind: none`** на первое время: механизм «смежных фокусов»
  (`flags`) опирается на flag-вопросы недельной самопроверки, которых пока
  почти нет — включим вместе с диагностикой.

## Структура, в которую материал в итоге ложится (`content/modules/anx.yaml`)

Проверяется валидатором при загрузке (`check_module` в
[../../../backend/app/content_loader.py](../../../backend/app/content_loader.py)):

- **6 недель ровно**, в каждой **7 дней ровно**;
- у каждого дня: фокус, задание (с подзадачами), **ровно 3 вопроса
  для размышления** (квиз необязателен);
- если есть недельная самопроверка — **ровно 10 вопросов** со скрытыми весами;
- **зоны** GREEN/YELLOW/RED, покрывающие весь диапазон баллов без разрывов
  (только если есть самопроверка);
- **5 утренних + 5 вечерних маркеров состояния** на всю программу;
- аудио/текстовые практики — свободное количество, коды уникальны;
- финальный продукт программы (`protocol`, как у BOUND) и постмодуль.

```
ANX-W1-FINAL.md            сценарий финальной аудиопрактики дня 7 (текст, без записи)
```
