# Вертикаль для спортсменов — новое направление

Отдельная вертикаль, не из десяти направлений входной самооценки. Обсуждалась
с партнёром. Структура программы (6 недель, аудио, самопроверки) предположительно
та же, что у остальных, но это стоит подтвердить до того, как материал начнёт
стекаться — спортивный контекст может потребовать других маркеров или ритма.

## Кладите сюда любые материалы по этой теме

Методический текст, черновик недели, идея практики, разговор с партнёром —
всё вперемешку, в любом формате.

## Структура, в которую материал в итоге должен лечь (если не решено иначе)

- **6 недель ровно**, в каждой **7 дней ровно**;
- у каждого дня: фокус, задание, квиз, **ровно 3 вопроса для размышления**;
- **10 вопросов недельной самопроверки** со скрытыми весами;
- **5 утренних + 5 вечерних маркеров** на программу;
- **24 аудио-практики**: 6 недель × 4.

Эта вертикаль — наименее определённая из всех. Если формат значимо отличается
(например, не 6 недель, а другой цикл), стоит обсудить это явно до того, как
материал будет написан под неверную структуру.
