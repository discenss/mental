## Имя файла сценария

**Обязано совпадать с кодом аудио**, чтобы потом не путаться, какой текст к
какой записи:

```
REAL-W1-A1.md       → AUDIO_REAL_W1_A1.mp3
REAL-W1-FINAL.md    → AUDIO_REAL_W1_FINAL.mp3
```

Слоты: A1 — дни 1–2, A2 — дни 3–4, A3 — дни 5–6, FINAL — день 7.

## Шапка сценария

```markdown
# REAL-W1-A1

- Код: AUDIO_REAL_W1_A1
- Хронометраж: ~6 минут
- Статус: черновик | утверждён | записан

[пауза 3 сек] — пауза в начитке, диктору
[мягче] — интонационная пометка, диктору

---

<текст>
```

После записи обновите `duration_sec` и `size_bytes` в `audio_map` в
`content/modules/real.yaml` — сейчас там значения заглушки у всех 24 записей.
