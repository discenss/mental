# audio-scripts/ — сценарии аудио-практик

Текст, который читает диктор. Из этих файлов получаются mp3 в `content/audio/`.

## Структура

У каждой программы **24 аудио-практики**: 6 недель × 4 слота.

| Слот | Дни недели | Что это |
|---|---|---|
| A1 | 1–2 | первая практика недели |
| A2 | 3–4 | вторая |
| A3 | 5–6 | третья |
| FINAL | 7 | итоговая практика недели |

Имя файла сценария **совпадает с кодом аудио** в [../../content/modules/](../../content/modules/):

```
real/REAL-W1-A1.md     → AUDIO_REAL_W1_A1.mp3
real/REAL-W1-FINAL.md  → AUDIO_REAL_W1_FINAL.mp3
bound/BOUND-W3-A2.md   → AUDIO_BOUND_W3_A2.mp3
```

Темы всех 24 практик REAL уже заданы в `content/modules/real.yaml` (поле `title`
в `audio_map`) — сценарий пишется под существующую тему, а не наоборот.

## Текущее состояние

**Реальной озвучки пока нет.** Все 48 файлов в `content/audio/` — одна и та же
заглушка (одинаковый md5, 6 007 262 байта). Сценарии и запись ещё предстоят.

## Шапка каждого сценария

```markdown
# REAL-W1-A1

- **Код:** AUDIO_REAL_W1_A1
- **Тема:** Со мной не что-то не так — я начинаю замечать, где остановился
- **Дни:** 1–2, неделя 1
- **Хронометраж:** ~6 минут
- **Статус:** черновик | утверждён | записан

---

<текст для диктора>
```

## Для диктора

- Паузы помечаем явно: `[пауза 3 сек]`.
- Интонационные указания — курсивом в квадратных скобках: `[мягче]`, `[медленнее]`.
- Эти пометки **не читаются вслух** — они для записи.

После записи обновите `duration_sec` и `size_bytes` в `audio_map` соответствующего
YAML: сейчас там проставлены значения заглушки (375 сек / 6007262 байта) у всех 24 записей.
